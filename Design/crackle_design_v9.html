Solve icon — magnifying glass with a letter "A" inside the lens. Rust throughout. The letter ties it to the word game context rather than looking like a generic search. When inactive it drops to #555568.

Stats icon — four-bar chart. Bars use the exact green and yellow from the guess tiles: dark green (#376b4a), dark yellow (#7a6020), bright green (#8ed9a8), bright yellow (#e8c060). When active the stats label turns green to match the tallest bar. When inactive, all bars drop to a single muted tone.

Settings icon — standard gear, always in the muted UI colour #a8a8c4 when active, #555568 when inactive. No colour competition — it's a utility, not a feature.
